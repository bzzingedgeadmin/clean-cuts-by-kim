# Clean Cuts By Kim - Barber & Grooming Studio Website

Official high-converting landing page and website for **Clean Cuts By Kim** located in Cedar Park, TX (11200 Lakeline Mall Dr).

## Features
- **Modern Dark Barber Aesthetic**: Designed specifically for high-end men's grooming & hair styling.
- **Service Menu & Transparent Pricing**: Clear service breakdowns for haircuts, skin fades, beard sculpting, and hot towel shaves.
- **Booksy Direct Integration**: Seamless CTA buttons directing clients straight to Kim's Booksy booking engine.
- **Portfolio Showcase**: Interactive haircut gallery with style filters.
- **Local SEO & Schema.org**: Pre-configured `BarberShop` structured metadata for Google Maps & Local search dominance.

## Setup & Deployment
1. Simply upload or push this directory to Vercel or Netlify.
2. Zero build steps required (100/100 Lighthouse performance).
